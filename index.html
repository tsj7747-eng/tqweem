الأدوار والصلاحيات

الدورماذا يستطيع
مشرف (admin)كل شيء، ويغيّر أدوار الآخرين من لوحة Supabase
محرِّر (editor)يعدّل الحالات ويرفع الملفات ويحذفها
مُشاهد (viewer)يطّلع ويحمّل الملفات فقط، ولا يستطيع تغيير شيء
لإضافة شخص: Supabase ← Authentication ← Users ← Add user، ثم غيّر دوره من Table Editor ← profiles ← عمود role. كل مستخدم جديد يبدأ «مُشاهد» تلقائيًا.
